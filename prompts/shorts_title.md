# 쇼츠 제목·태그 생성 프롬프트

> 이미 잘린 클립의 자막 텍스트를 받아 **유튜브 쇼츠용 제목·해시태그**를 생성합니다.
> `highlights.json`의 `title`을 다시 다듬거나, 사용자가 "쇼츠 제목 더 자극적으로" 같은
> 요청을 했을 때 사용합니다.

---

## 입력
- 클립 시작~끝 사이의 STT 텍스트
- (선택) 게임명·콘텐츠 카테고리

## 출력 (JSON)

```json
{
  "title_options": [
    "방장 치트키 발동.exe",
    "이게 운빨? 실력?",
    "도네받고 폭소한 썰"
  ],
  "tags": ["롤", "한타", "역전", "쇼츠", "스트리머"],
  "description": "어제 방송 중 가장 미친 순간\n\n#쇼츠 #롤 #한타",
  "thumbnail_text": "이게 됨?"
}
```

---

## 작성 규칙

### 제목 (3개 후보)

- **15자 이내** (모바일 잘림 방지)
- 호기심 트리거: 의문형 (`이게 됨?`, `미친 운빨?`)
- 결과 스포일러 ❌ (`방장이 이김!` X → `이게 가능?` O)
- 3개 중 하나는 **클릭베이트 강함**, 하나는 **담백**, 하나는 **유머**
- 이모지 ❌ (쇼츠는 텍스트만)

### 태그 (5~8개)

- 게임명/콘텐츠명 (필수)
- 상황 키워드 (한타/역전/도네/낚시 등)
- 일반 (`쇼츠`, `스트리머`, `재미있는`)
- 본인 채널명 (스트리머가 자기 닉으로 수정)

### 설명

- 첫 줄에 가장 임팩트 있는 한 줄
- 두 번째 단락에 해시태그
- 50자 이내

### 썸네일 텍스트

- 5~8자
- 큰 글씨로 화면에 박을 거라 짧고 강하게
- 예: `이게 됨?`, `역대급`, `방장 미침`, `도네 폭주`
