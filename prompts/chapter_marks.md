# 롱폼 챕터 마크 생성 프롬프트

> 롱폼 하이라이트 모음(`longform/highlight_full.mp4`)의 유튜브 설명란용 챕터를 생성합니다.
> `cut_clips.py`가 자동 생성한 `chapters.txt`를 다듬거나, 새로 작성할 때 사용.

---

## 입력
- `highlights.json`의 `longform_chapters` 중 `include_in_highlight: true` 항목
- 각 챕터의 STT 텍스트 (transcript.json에서 해당 구간)

## 출력

`<YYMMDD>/longform/chapters.txt` 형식:

```
00:00 인트로 — 오늘은 솔로랭크 종일
01:23 [1판] 미드 르블랑 — 초반 솔킬
12:40 [1판] 한타 4킬, 역대급 캐리
24:15 도네 받고 박장대소
35:00 [2판] 정글 하드캐리
58:45 마무리 인사
```

---

## 작성 규칙

### 시간 형식
- `MM:SS` (60분 미만) 또는 `HH:MM:SS`
- 첫 챕터는 반드시 `00:00`

### 제목 톤
- **앞부분에 카테고리 태그** (`[1판]`, `[잡담]`, `[도네]`, `[엔딩]`)
- 카테고리 후 짧은 설명 (10자 내외)
- 후킹 강하게 (시청자가 "이 챕터부터 볼까?" 싶도록)

### 분량
- 너무 잘게 ❌ (1분 미만 챕터 X)
- 한 챕터 5~15분이 이상적
- 전체 챕터 5~10개

### 좋은 예
```
00:00 오프닝 / 오늘 패치 잡담
03:45 [1판] 미드 야스오 — 초반부터 솔킬
18:20 [1판] 미친 한타 (4킬)
27:30 도네 폭주 — 가장 웃긴 사연
35:00 [2판] 정글 하드캐리
50:15 [3판] 충격의 패배
1:02:00 시청자 채팅 읽기
1:15:30 마무리 인사
```

### 나쁜 예
```
00:00 시작
05:00 게임
10:00 게임
15:00 게임
```
(반복 + 정보 0)
