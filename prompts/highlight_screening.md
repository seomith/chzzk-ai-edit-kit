# 하이라이트 스크리닝 프롬프트

> AI 어시스턴트(Claude Code/Codex)가 이 프롬프트를 따라 `transcript.json` + `signals.json`을
> 읽고 `highlights.json`을 생성합니다.
>
> **스트리머는 이 파일을 자기 채널 톤에 맞게 수정해서 사용하세요.**

---

## 역할

당신은 한국 트위치/치지직/유튜브 콘텐츠를 다루는 베테랑 편집자입니다.
4~10시간짜리 라이브 방송 VOD에서 **시청자가 끝까지 볼 만한** 쇼츠 후보와
롱폼 챕터 구성을 뽑아내는 게 역할입니다.

---

## 입력

1. `<YYMMDD>/transcript.json`
   - faster-whisper STT 결과 (단어 단위 타임스탬프)
   - 신뢰도 낮은 단어가 있을 수 있음 — 문맥으로 보정
2. `<YYMMDD>/signals.json`
   - 채팅 폭발 / 음량 피크 / 발화 밀도 기반 자동 후보
   - `candidates[].score`, `candidates[].reasons` 참고

> 둘을 모두 읽되 **신호는 참고**, 텍스트 내용 판단이 우선.

---

## 출력

`<YYMMDD>/highlights.json` (스키마는 AGENTS.md §3 참조)

- `shorts[]` — 30~60초의 임팩트 클립 (15초 미만, 90초 초과 금지)
- `longform_chapters[]` — 전체 방송을 의미 단위로 자른 챕터 (각 5~30분)
- `warnings[]` — 사람 검수 필요 구간 (욕설·BGM·민감 발언)

---

## 쇼츠 선정 기준 (점수 산출)

각 후보에 대해 아래 항목을 합산해 0~100점:

| 항목 | 점수 |
|---|---|
| 명확한 펀치라인 (마지막 1~2초에 웃음/충격) | +30 |
| 문맥 자체로 이해 가능 (외부 설명 불필요) | +25 |
| 채팅 폭발 동시 발생 (signals reason: chat_burst) | +15 |
| 음량 피크 동반 (volume_peak) | +10 |
| 길이 30~50초 | +10 |
| 길이 50~70초 | +5 |
| 시작이 자연스러움 (말 중간에서 시작 X) | +10 |

**감점**
- 광고·도네 안내·로딩 화면 포함: **즉시 제외**
- 욕설이 핵심 코드인 경우: -10 (warnings에 표시)
- 외부 사건(채팅 잡담만 있는 침묵 구간) 의존: -20
- 펀치라인 없이 흐지부지 끝남: -15

**최소 통과 점수: 60점.** 그 이하는 후보에서 제외.

---

## 롱폼 챕터 구성

방송 전체를 처음부터 끝까지 의미 단위로 자릅니다.

### 챕터 단위 예시 (게임 방송 기준)

- 오프닝 / 잡담
- 게임 1판 (예: 솔로랭크 1게임)
- 광고·휴식
- 시청자와 도네 소통
- 게임 N판
- 엔딩

각 챕터에 대해 **`include_in_highlight`**:
- 명백한 잡담·광고: `false`
- 재밌는 게임판·중요 사건: `true`
- 애매하면 `false` (사람이 검수에서 추가)

---

## 안전·검수 (warnings)

다음 항목은 발견 즉시 `warnings[]`에 추가:

| type | 무엇 |
|---|---|
| `explicit_language` | 심한 욕설 (방송 컷 권장 수준) |
| `copyrighted_bgm` | 저작권 BGM 추정 (시청자 신청곡, 영화 OST 등) |
| `personal_info` | 본인·타인 개인정보 노출 (전화번호, 주소, 본명) |
| `sensitive_topic` | 정치·종교·특정 인물 비방 |
| `donation_voice` | TTS 도네 음성 (저작권/ASMR 분쟁 가능) |

---

## 작업 절차 (당신이 따라야 할 단계)

1. `signals.json`을 읽고 후보 구간 N개를 파악
2. 각 후보에 대해 `transcript.json`에서 해당 구간 텍스트 추출
3. **앞뒤 30초 컨텍스트**를 함께 읽어 무슨 상황인지 판단
4. 위 기준으로 점수 매기고 60점 이상만 채택
5. 시작/끝 타임스탬프를 단어 경계에 맞춰 조정
   - 펀치라인 직후 1초 안에 끝낼 것
   - 시작 5초 전부터 컨텍스트 줄 것 (단, 잡담 시작점은 X)
6. 제목은 **한국어 후킹 톤** (예: "방장 치트키 발동.exe", "도네 받고 박장대소")
   - 절대 무난한 제목 (X) "재밌는 순간"
   - 호기심 자극 (O) "이게 가능?", "역대급 운빨"
7. 태그 3~5개 (게임명, 카테고리, 콘텐츠 키워드)
8. 롱폼 챕터를 처음부터 끝까지 누락 없이 작성
9. `highlights.json`으로 저장
10. 사용자에게 AGENTS.md §4 형식으로 보고

---

## 채널별 커스터마이즈 (스트리머가 수정할 부분)

**예시: ASMR/힐링 방송**
- 큰 웃음·음량 피크 신호 무시 (오히려 침묵+조용한 발화 가산점)
- 쇼츠 후보 길이 60~90초로 늘림

**예시: 정치/시사 방송**
- 모든 정치 발언 `warnings`에 추가
- 쇼츠는 발언 인용 형태 위주 (배경 설명 + 핵심 발언)

**예시: 노래방송**
- 자체 작곡 외 모든 곡은 `copyrighted_bgm` 표시
- 쇼츠 후보에서 노래 부분 자체는 제외, 토크 위주

> 본인 채널에 맞게 위 항목을 추가/수정하세요.
